🌐 ConnectSphere – Real-Time Communication & Collaboration Platform

ConnectSphere is a real-time communication and collaboration platform developed using Django. It allows users to schedule meetings, join video conferences, communicate through chat, share screens and exchange files in a collaborative virtual environment.

🚀 Features :-

User Authentication: User registration, login and profile management.

Meeting Management: Create, schedule and join meetings.

Video Conferencing: Real-time video meetings using Jitsi Meet.

Screen Sharing: Share your screen during meetings.

Meeting Chat: Communicate with participants through chat.

File Sharing: Upload and share files with meeting participants.

Participant Management: View participants in a meeting.

Responsive UI: User-friendly interface for different screen sizes.

Collaborative Whiteboard: Designed for interactive collaboration (if enabled in your current build).
